# assets/

`logo.png` = โลโก้บริษัทที่แอปใช้แสดงบนหน้าจอ

**ตอนนี้เป็นรูปวาดชั่วคราว ยังไม่ใช่โลโก้จริง**
เปลี่ยนเป็นไฟล์จริงด้วยคำสั่งเดียว (สร้างไอคอน Android + ไอคอน PWA ให้ครบด้วย):

```
python tools/set_logo.py "<path โลโก้.png>"
```

ห้ามแก้ไฟล์นี้ด้วยมือ — ใช้สคริปต์ เพื่อให้ทุกที่ในระบบใช้รูปเดียวกัน
